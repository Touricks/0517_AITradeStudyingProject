**建议算法**
把行为训练升级为 `StockContext -> BehaviorLogic -> TrainingDecision` 四层。


1. 股票上下文层  
   新增 `build_stock_context(symbol)`，统一调用：
   - `get_quote`：现价、涨跌幅、成交额、换手、振幅
   - `get_kline`：近 3/5/20 日涨幅、波动率、是否连续上涨、离均线/近期高低点距离
   - `get_announcements`：近公告风险
   - `get_news`：事件/题材热度
   - `search_reports`：研报背景  
   输出只作为“训练背景”，不输出买卖信号。

3. 行为逻辑分析层  
   把用户理由和股票上下文做对照：
   考虑以下内容:
    1. 股票基本面：公司财务运营状况，例如公司的现金流
    2. 股票技术面：股票和公司是独立的。股票买卖的现金流
   - 用户说“最近涨得强/怕错过” + 近 3/5 日涨幅高 => `追涨/FOMO`
   - 缺少 `stop_loss/max_loss/holding_period/invalid_condition` => `计划缺失/止损缺失`
   - 仓位高 + 用户画像风险等级高 => `仓位不匹配`
   - 用户说基本面逻辑，但只提供短线价格理由 => `理由与周期不一致`
   - 历史记忆里反复出现同类 tag => `重复行为模式`

4. 训练决策层  
   建议评分拆成：
   - 计划完整度 30
   - 风险预算 25
   - 行为一致性 20
   - 股票上下文意识 15
   - 历史重复惩罚 10  
   硬性拦截项：无止损、无最大亏损、情绪 FOMO、仓位过高、重复历史错误。输出仍然是“是否满足训练规则”，不能说“可以买/该卖”。
