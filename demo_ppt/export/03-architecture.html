Architecture 03
前端 + 后端 + MCP
系统把“评测链路”和“Agent 个性化链路”分开。

React 前端

评测问卷、训练表单、K 线与上下文面板，负责用户真实交互。

Python API 后端

交易能力评估、行为训练、memory 写入、Kimi 调用与市场数据封装。

用户画像 Memory

问卷结果、能力画像、训练记忆、风险标签和证据摘要。

STDIO MCP

只读提取画像，供 Agent 在后续对话中参考。

Agent 个性化建议

解释用户画像、指出训练重点、给出学习路径；不替用户答题，也不输出交易信号。
