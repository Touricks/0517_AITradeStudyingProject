Runbook 07
本地启动流程
先配置后端，再打开前端，最后接入 MCP。
01

配置环境变量

`AITrading/config/.env` 写入 Kimi API 与东方财富 Provider 配置。

02

启动后端

`cd AITrading`
`python3 scripts/dev_server.py`

03

启动前端

`cd AITradingFrontend`
`npm install`
`npm run dev`

04

接入 MCP

修改 `.mcp.json` 绝对路径，Agent 通过只读 tool 读取画像。

关键接口：GET /health · POST /api/questionnaires/full_assessment/submit · POST /api/training/check · GET /api/memory
